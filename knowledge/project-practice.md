# Agent 项目练习

第一步：运行离线演示，观察 list_notes、search_notes、read_note 的调用顺序。
第二步：添加自己的 Markdown 笔记，并用同一个问题比较添加前后的检索结果。
第三步：配置 API Key 和模型，体验模型自主选择工具的真实 Agent 模式。
第四步：阅读 agent.js，理解函数调用结果如何回传以及为什么必须保留模型输出项。
第五步：添加测试，覆盖检索失败、工具参数错误、超出调用上限和伪造引用。
第六步：增加一组评估问题，比较关键词检索与未来的向量检索效果。
第七步：记录你亲自实现的改动、评估结果和局限，形成可信的项目介绍。
API Key 只能通过服务端环境变量读取，不能放入公开仓库或截图。
启用真实模型模式会把用户问题和工具返回的笔记内容发送给模型服务；练习应使用非敏感资料。

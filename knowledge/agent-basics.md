# Agent 基础 / Agent basics

Agent 是围绕目标反复执行“选择行动、调用工具、观察结果、决定下一步”的程序。
普通聊天主要生成文字；Agent 还能调用工具，根据工具结果决定后续行动。
工具调用 function calling 是模型提出结构化调用请求，由应用执行并把结果交回模型。
系统指令定义角色、目标和边界；用户问题描述当前任务；工具结果提供外部证据。
本项目的三个工具分别负责列出笔记、检索关键词、读取带行号的笔记。
Agent loop 必须有停止条件：获得最终答案、超过轮数上限、超过调用次数上限或遇到不可恢复错误。
运行轨迹 trace 记录可观察的模型轮次和工具调用，不展示模型的私有思维过程。
离线 demo 使用确定性规则模拟工具选择；真实模式由模型动态决定工具和参数。
提示注入 prompt injection 是资料中夹带指令试图改变程序行为；笔记应被视为数据，不能授予权限。
工具权限要在代码中执行，例如阻止路径穿越、限制文件大小和限制调用次数。
引用只能证明某个文件和行号存在，不能自动证明回答与来源语义一致。

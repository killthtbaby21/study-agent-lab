# 检索增强生成 / RAG

RAG 即 Retrieval-Augmented Generation：先检索与问题相关的资料，再把资料提供给模型生成回答。
关键词检索依赖字面重合；向量检索依赖语义相似度，两者也可以组合。
本项目只实现轻量关键词检索：英文词与中文双字片段计分，没有 embedding 或向量数据库。
读取笔记时保留文件名和行号，使回答能够标注可核对的来源。
检索不到资料时应明确返回资料不足，不能让模型伪造来源。
RAG 和 Agent 可以组合：Agent 根据需要主动选择检索工具，并在证据不足时继续检索。
资料切块 chunking 可按标题、段落或固定长度进行；重叠部分可减少上下文被切断的问题。
检索质量可以通过相关资料命中率和无关问题的正确拒答比例评估。
生成质量需要另行评估：答案是否正确、引用是否支持结论、是否承认资料边界。
